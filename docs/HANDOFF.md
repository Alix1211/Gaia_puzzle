# GAIA WELLNESS ROYALE 작업 인수인계

기준: **2026-11-01 · v0.5 (회원 24명·RPG 성장)**
저장소: `Alix1211/Gaia_puzzle`  
이 문서는 새 대화창에서 첫 번째로 읽는 작업 현황 기록입니다.

## 1. 현재 확정된 게임 방향

- 가이아 시티의 **고급 웰니스 클럽**을 배경으로 한 블랙·골드 럭셔리 매치 퍼즐 대전.
- 8×8 퍼즐판이 가장 중요합니다. 아이콘 테두리는 **얇게**, 골드 광택·시인성 유지.
- 세로: 위쪽 회원 상반신 초상화, 화면 중앙 8×8 퍼즐, 아래 트레이너 UI. 가로: 8×8 보드를 크게, 초상화 오른쪽, UI 왼쪽.
- 사용자 기준 세계관: 자발성·독립된 시민권, 하드한 상황과 명랑한 일상의 공존. **블랙·골드**는 이번 게임의 별도 확정 미감입니다.
- **물리·성적·모럴·복종 네 요구치를 각각 다르게 설정**합니다. 후반에는 한두 수치를 더 크게 요구할 수 있습니다. 합계 점수나 한 항목만 채우는 조건으로 바꾸지 않습니다.
- 하트는 적에게 가하는 공격이 아니라 HP 회복입니다. AI는 같은 퍼즐판을 사용해 플레이어의 HP를 깎습니다.

## 3. 버전 및 파일 구조

```text
index.html                         # v0.4 실행본, 모든 코드/이미지/음원 내장
README.md                          # 게임 소개 및 실행 안내
source/gaia-match-engine.js        # 매치 판정, 특수블록과 낙하
source/gaia-v03-fx.js              # 레이저, 폭발, 조각 파티클
source/gaia-v04-runtime.js         # 전투, AI, UI, 초상화, 저장
source/gaia-members.js             # 24명 이름·성격·목표·AI·보상·등급
source/gaia-v04-audio.js           # 음악/효과음/재생 전환/음소거
source/gaia-v04-overrides.css      # 레이아웃과 연출 오버라이드
source/gaia-royale-template.html   # HTML 기준 템플릿
source/rebuild-gaia-v04.mjs        # assets+audio → 독립 HTML

assets/tiles/raw/                  # 새 금색 패들/볼개그 원본 2장
assets/tiles/previous-v04/         # 교체 전 패들/볼개그 WebP 백업
audio/                             # 원본 BGM 3종 + 최적화한 효과음 6종
docs/RELEASE-v0.4.md              # 해당 버전 설명
docs/RELEASE-v0.5.md              # 이번 버전 변경사항
```

원본 24장은 ID 01~24로 고정 연결했습니다. **로지로프(갈색 머리)와 초선(비녀 머리)**은 사용자 지정입니다. 나머지 22명의 이름·직업·등급·AI/요구치는 이번 초안에서 생성한 설정이므로 추후 사용자가 수정할 수 있습니다. 이미지 파일명과 원본 파일은 유지했습니다.

- 기존 그림을 새로 그리거나 색/의상/표정을 임의 수정하지 않습니다.
- 코드 프레임을 두껍게 바꾸지 않습니다. 프레임 자산 이미지를 기준으로 합니다.
- 게임 규칙·전투 방식·특수효과를 설명 없이 단순화하지 않습니다.
- 24명 소스·이미지 연결은 완료했지만 **Android 실기기 24명 전수 검증까지 완료했다고 말하지 않습니다.**
- 업로드한 것과 실제 게임에 연결된 것을 구분합니다.
- 새 작업 시 이전 HTML이나 저장된 플레이 기록을 덮어쓰지 않습니다.
