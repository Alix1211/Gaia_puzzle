# GAIA WELLNESS ROYALE 작업 인수인계

기준: **2026-11-01 · v0.4**  
저장소: `Alix1211/Gaia_puzzle`  
이 문서는 새 대화창에서 첫 번째로 읽는 작업 현황 기록입니다.

## 1. 현재 확정된 게임 방향

- 가이아 시티의 **고급 웰니스 클럽**을 배경으로 한 블랙·골드 럭셔리 매치 퍼즐 대전.
- 8×8 퍼즐판이 가장 중요합니다. 아이콘 테두리는 **얇게**, 골드 광택·시인성 유지.
- 세로: 위쪽 회원 상반신 초상화, 화면 중앙 8×8 퍼즐, 아래 트레이너 UI. 가로: 8×8 보드를 크게, 초상화 오른쪽, UI 왼쪽.
- 사용자 기준 세계관: 자발성·독립된 시민권, 하드한 상황과 명랑한 일상의 공존. **블랙·골드**는 이번 게임의 별도 확정 미감입니다.
- **물리·성적·모럴·복종 네 요구치를 각각 다르게 설정**합니다. 후반에는 한두 수치를 더 크게 요구할 수 있습니다. 합계 점수나 한 항목만 채우는 조건으로 바꾸지 않습니다.
- 하트는 적에게 가하는 공격이 아니라 HP 회복입니다. AI는 같은 퍼즐판을 사용해 플레이어의 HP를 깎습니다.

- 컨트롤러: **30세션 자동 플레이 통과**, 게임판 항상 64칸.

- 사운드 모듈: **90/120/150 전환, 음소거, 반복 효과음, 반응음 중복 제한, 시작 전 무음** 테스트 통과.
- ZIP/단일 HTML 포장과 리빌드 결과의 SHA-256 일치 검증 완료.
- 브라우저 실렌더·Android 실제 소리·터치/프레임은 미검증. 기존 테스트 기록을 실기기 검증으로 바꿔 적지 말 것.

## 5. 다음 작업 (아직 착수하지 않음)

1. **24명 원본 시트 검수:** 각 시트는 네 포즈가 가로로 배치되어 있으며, 크기가 일정하지 않습니다(예: 2752×1536, 2880×1440, 기존 1408×704). 인물별 식별과 크롭 경계 확인. 외곽 배경/잔여물 누끼 주의.
2. **회원 정보 결정:** 기본 두 명 포함, 회원 총 24명. 이름·등급·목표 네 수치·AI 난이도는 사용자 확정 후 매핑합니다. 파일명으로 인물 설정 추측 금지.
3. **패들·볼개그 업데이트:** `assets/tiles/raw/`의 새 금색 2장으로 게임용 WebP를 만들되, 기존 64블록 가독성·얇은 프레임을 유지. **아직 게임에 적용한 게 아닙니다.**
4. 포즈/회원 변경에서 메모리와 프레임을 확인하면서 캐릭터 24명 확장.
5. 사용자 Android iPlay70 mini Pro에서 BGM 재생과 화면 비율/실제 이펙트 검증.
6. 작업 전후 이 문서에 커밋·파일·시험 결과·미완료 사항을 덧붙이기.

## 6. 매우 중요한 금지사항

- 기존 그림을 새로 그리거나 색/의상/표정을 임의 수정하지 않습니다.
- 코드 프레임을 두껍게 바꾸지 않습니다. 프레임 자산 이미지를 기준으로 합니다.
- 게임 규칙·전투 방식·특수효과를 설명 없이 단순화하지 않습니다.
- 24명이 모두 플레이 가능하다고 말하지 않습니다. **현재는 2명**입니다.
- 업로드한 것과 실제 게임에 연결된 것을 구분합니다.
- 새 작업 시 이전 HTML이나 저장된 플레이 기록을 덮어쓰지 않습니다.
