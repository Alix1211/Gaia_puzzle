# GAIA WELLNESS ROYALE 작업 인수인계

## 대사 24명 실제 적용 · 2026-11-02

- `source/gaia-dialogues.json`에 회원 24명 × 8문장 = **총 192문장**을 반영했습니다. `intro` 2, `hit` 2, `chain` 1, `counter` 1, `heal` 1, `clear` 1입니다.
- `source/gaia-v04-runtime.js`에서 네 요구치를 모두 달성해 승리하면 해당 회원의 `clear` 대사를 **SESSION COMPLETE 모달에 표시**합니다. 기존 5개 이벤트는 그대로 작동하며 대사 데이터만 교체했습니다.
- **현재 문장은 임시 적용본입니다.** 사용자는 일부 대사가 청유·부탁형으로 반복되고 극적인 반응이 부족하다고 지적했습니다. 검토를 더 미루지 말고 게임에는 일단 적용하자는 요청에 따른 작업입니다. 완성된 톤의 정본으로 취급하지 않습니다.
- 상점 대신 회원의 자발적인 **조공**으로 소모품·아이템을 공급한다는 방향이 제안됐습니다. 금품 수수 금지 규정과 VIP 관행의 모순이 코미디 핵심입니다. **아이템 지급, 인벤토리, 확률, 상점 제거는 아직 구현하지 않았습니다.**
- 캐릭터 수치, 레벨 계산, 게임 규칙, 초상화, 저장 스키마, 효과음·BGM 및 화면 레이아웃은 변경하지 않았습니다. Android 실기기 확인은 별도입니다.

- 회원 24명의 `intro/hit/chain/counter/heal` 대사 로컬 파일 `source/gaia-dialogues.json`으로 작성. 빌드 시 오프라인 HTML에 자동 내장. 초상화 위에 상자 없는 텍스트/그림자만 표시.

- **세로 피격 수정:** 가로 모드의 `translateX(-50%)` 피격 애니메이션이 세로 초상화에 적용되던 우선순위 충돌을 수정. 세로는 제자리 기준 ±3px 흔들림, 전격 전용 움직임은 그대로.

## 1. 현재 확정된 게임 방향

- 가이아 시티의 **고급 웰니스 클럽**을 배경으로 한 블랙·골드 럭셔리 매치 퍼즐 대전.
- 8×8 퍼즐판이 가장 중요합니다. 아이콘 테두리는 **얇게**, 골드 광택·시인성 유지.
- 세로: 위쪽 회원 상반신 초상화, 화면 중앙 8×8 퍼즐, 아래 트레이너 UI. 가로: 8×8 보드를 크게, 초상화 오른쪽, UI 왼쪽.
- 사용자 기준 세계관: 자발성·독립된 시민권, 하드한 상황과 명랑한 일상의 공존. **블랙·골드**는 이번 게임의 별도 확정 미감입니다.
- **물리·성적·모럴·복종 네 요구치를 각각 다르게 설정**합니다. 후반에는 한두 수치를 더 크게 요구할 수 있습니다. 합계 점수나 한 항목만 채우는 조건으로 바꾸지 않습니다.
- 하트는 적에게 가하는 공격이 아니라 HP 회복입니다. AI는 같은 퍼즐판을 사용해 플레이어의 HP를 깎습니다.
