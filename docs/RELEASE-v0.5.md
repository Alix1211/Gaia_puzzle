# GAIA · WELLNESS ROYALE v0.5

2026-11-01 · **24명 회원 연결 / 금색 아이콘 교체 / 퍼즐 RPG 성장**

## 실행

루트 `index.html` 단일 파일에 모든 24명×4포즈 초상화·타일·BGM·효과음이 내장되어 있습니다. 다운로드 후 오프라인 실행 가능. 기존 `gaia-royale-v02` 로컬 저장 키를 그대로 사용하므로 레벨/XP/승수/음소거 값은 유지합니다.

## 주요 변경

1. 로지로프(갈색 긴 머리, 빨간 의상)를 **전속 회원**, 초선(비녀 올림머리, 분홍 의상)을 **센터 오너·무료 특별관리**로 확정. 두 명의 기존 목표와 4포즈 그림은 그대로 보존.
2. 남은 22명은 원본 4포즈 시트별로 다른 회원으로 연결. 이름·성인 나이·직업·성격·프로필·마조력·등급·권장 레벨·개별 목표·AI 정확도와 타격 압박을 부여. 상세 명단: `docs/MEMBER_ROSTER.md`.
3. 회원 선택 화면: 24명 카드, 등급 탭, 선택한 회원의 초상화·프로필·네 가지 요구치·권장 Lv·기록을 확인하고 시작.
4. 루키 → 실버 → 골드 → VIP → VVIP 순서로 목표 합계와 AI의 좋은 수 선택 확률·피해량이 높아집니다. 특별 회원은 별도 등급. 높은 권장 Lv도 자유롭게 도전할 수 있습니다.
5. 트레이너는 ATK 100부터 레벨당 +3.5%p, 최대 HP 225부터 레벨당 +6. **반복 승리 XP**, 회원별 첫 완료 보너스 +20, 누적 완료 횟수 저장.
6. 사용자가 금색으로 수정한 **패들·볼개그 아이콘 2종**을 실제 8×8 블록에 적용. 기존 그림은 백업했고 나머지 3종 블록과 프레임은 불변.
