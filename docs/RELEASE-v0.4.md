# GAIA · WELLNESS ROYALE v0.4

## 실행

`index.html`을 휴대폰 또는 PC 브라우저에서 열면 됩니다. 인터넷 연결이나 설치가 필요하지 않습니다. 이미지·BGM·효과음이 모두 HTML 안에 들어 있습니다.

브라우저의 자동 재생 제한 때문에 BGM은 **회원 선택이나 세션 시작을 처음 누른 뒤**에 나옵니다. 화면 아래 **♪** 버튼으로 BGM과 효과음을 함께 켜고 끕니다. 음소거 상태는 자동 저장됩니다.

## 이번 업데이트 — 오디오

| 구분 | 파일 | 적용 |
| --- | --- | --- |
| BGM | USE_타격음악_90BPM_합본.mp3 | 회원 선택 화면 |
| BGM | USE_타격음악_120BPM_합본.mp3 | MEMBER 01 |
| BGM | USE_타격음악_150BPM_합본.mp3 | MEMBER 02 |
| 효과음 | 음원.zip → 찰싹1.wav, 찰싹2.wav, 찰싹3.wav | 짧은 타격 샘플 3종으로 편집하여 순환 재생 |
| 효과음 | 음원.zip → 아앗_놀람i.mp3, 기쁜반응.mp3, 지친소리_한숨.mp3 | 회원 반응에 드물게 삽입, 연쇄 중 중복 제한 |

3곡은 **타격 효과음이 아니라 BGM**으로만 사용합니다. 120초 길이 원본 MP3를 보존하고 반복 재생합니다. 기존 레이저·폭발·전기 등의 합성 효과음과 v0.3 애니메이션은 유지했습니다.

압축파일 속 음원 23종은 모두 확인해 압축을 풀었고, 당장 필요한 6종만 편집해서 게임에 탑재했습니다. 나머지는 향후 미니게임/추가 효과에 쓸 수 있도록 원본 `음원.zip`에 남겨 두었습니다.

## 게임

- 8×8 매치 퍼즐. 3개 이상 연속, 2×2 사각, 4·5개, T/L, 특수블록 조합, 연쇄 낙하.
- 타격·성적·모럴·복종 네 수치를 **각각 지정된 목표까지** 채우면 승리합니다.
- AI도 같은 판을 매치하며, AI 턴에는 트레이너 HP가 감소합니다.
- 회원별 난이도와 초상화 반응 4컷, 강화, 경험치, 자동 저장이 포함되어 있습니다.

## 개발 소스

- `assets/` — 게임용 WebP 이미지 16종.
- `audio/` — 원본 BGM 3곡과 게임용으로 편집한 SFX 6종.
- `source/` — 엔진, 화면·효과·사운드 코드, HTML 템플릿.
- 코드 수정 후 `node source/rebuild-gaia-v04.mjs`를 실행하면 `index.html`이 새로 생성됩니다. Node.js 외 별도 설치가 필요 없습니다.

v0.3 파일을 덮어쓰지 않은 독립 v0.4입니다.
