# GAIA WELLNESS ROYALE v0.6.1 · Android 사용성 수정판

v0.5 실행본을 기반으로 v0.6 기능과 사용자 피드백을 통합했습니다. 원본 24장/기존 그림/저장 키 유지.

## 적용 내용

1. 로지로프의 난이도 레벨은 트레이너 현재 레벨과 항상 동일, 초선은 정확히 5레벨 높음. 새 세션 시작 시 목표치와 AI 수치가 자동 갱신됨. 나머지 회원 22명은 기존 레벨/요구치 유지.
2. 전격 이펙트는 전기 문자 대신 초상화 뒤 하늘색·흰색 번개 여러 줄, 갈라지는 가지, 빠른 깜빡임과 캐릭터 떨림으로 표시.
3. 블록 확대·파괴 연출과 함께 녹음 타격음 재생. Android에서 동시 재생을 돕는 WebAudio 처리 추가.
4. 아직 한 번도 클리어하지 않은 회원은 회원 선택 카드에서 흑백과 금색 자물쇠. 클리어 시 컬러 복구. 자유 선택은 유지.
5. 24명 전용 대사: 도입/타격/연쇄/반격/회복 이벤트. 말풍선 박스 없이 초상화 위에 텍스트만 표시. 교체 가능한 데이터 파일 `source/gaia-dialogues.json`.
6. 가로 첫 블록 파괴 후 검은 판: `boardFx`의 desynchronized 캔버스 제거, `screen` 블렌드 및 애니메이션 종료 후 레이어 숨김.
7. 세로 피격 초상화 이동 오류: 가로용 X=-50% 이동을 세로에서 사용하지 않고 제자리 ±3px만 적용. 전격 전용 떨림은 보존.
8. 전체화면 버튼(⛶)과 설정의 BGM/효과음 독립 볼륨 슬라이더. 볼륨 변경은 재생 중 즉시 적용되고 이전 게임 저장 기록과 함께 저장됩니다.

## 확인/남은 일

- 소스와 완성 HTML 구문 검사, 두 볼륨 독립 조절/음소거, 이펙트 캔버스 자동 숨김 로직 테스트 통과. 초상화와 음원은 기존 파일 그대로.
- 실제 Android 기기 화면/효과음·전격 연출 실기 테스트는 아직 진행되지 않음.
- 다음 개발 작업은 사용자 Android 재시험 후 미니게임 연결.

## 재빌드

`node source/rebuild-gaia-v04.mjs` 실행. JSON 수정 후 같은 명령을 재실행하면 새 대사가 단일 `index.html`에 내장됩니다.
