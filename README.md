# GAIA WELLNESS ROYALE

가이아 시티 세계관의 **8×8 매치 퍼즐 대전 게임**입니다. 조교(플레이어)와 회원(AI)이 한 퍼즐판에서 번갈아 매치합니다. 기존 `Wellness` 경영 시뮬레이션 및 `Wellness-RPG`와는 별도로 제작한 게임입니다.

## 현재 버전

- **v0.4 오디오 통합판**: [index.html](index.html)을 브라우저에서 실행합니다. 이미지·음원 내장, 오프라인 사용 가능.
- 전투 대상 회원: 현재 **2명**. 캐릭터별 네 가지 표정·포즈가 이미 연결되어 있습니다.
- 추가 회원용 **24장의 원본 4포즈 초상화 시트**는 `assets/portraits/raw/`에 보존했습니다. 게임에는 아직 연결하지 않았습니다.
- 골드로 다시 칠한 패들·볼개그 원본 2장은 `assets/tiles/raw/`에 보존했습니다. 게임에는 아직 교체하지 않았습니다.

**현재 구현 상태, 미구현 작업, 검증 범위**는 [인수인계 문서](docs/HANDOFF.md)를 기준으로 판단하세요. 일단 돌아가는 기존 v0.4를 무리하게 바꾸지 마세요.

## 규칙

- 8×8, 기본 타일 5종: 패들(물리), 금색 토이(성적), 입술(모럴), 볼개그(복종), 하트(회복).
- 3개 이상 매치, 2×2 사각, 4·5개 매치, T/L, 특수블록 조합과 연쇄.
- 회원별 **물리·성적·모럴·복종 네 수치의 개별 목표를 전부 달성**해야 승리합니다.
- AI도 같은 보드에서 매치하며 AI 공격은 플레이어 HP를 소모합니다.
- 강화 에너지, 경험치, 회원 선택, 4포즈 초상화, 효과음·BGM 토글과 자동 저장.

## 소스 수정·재빌드

`source/`의 JavaScript·CSS·템플릿을 수정한 다음 Node.js로 아래를 실행합니다.

```bash
node source/rebuild-gaia-v04.mjs
```

`assets/webp/`, `audio/`를 읽어 하나의 `index.html`을 새로 만듭니다. 추가 패키지 없이 빌드됩니다. 캐릭터 확장은 먼저 원본 시트를 검수·분리한 뒤 구현해야 하며, 현재 리빌드 스크립트는 **기존 2명×4컷**을 내장하도록 되어 있습니다.

## 오디오

| 사용 장면 | BGM |
| --- | --- |
| 회원 선택 | 90 BPM |
| 회원 01 | 120 BPM |
| 회원 02 | 150 BPM |

원래 파일명에 `타격음악`이 있어도 위 3곡은 **BGM**입니다. 오리지널 효과음 패키지에서 `찰싹1/2/3` 일부와 반응음 3종을 편집해 사용합니다. 브라우저 자동 재생 제한 때문에 첫 사용자 터치 후 음악이 시작됩니다.

## 작업 원칙

1. 사용자의 최신 확정 지시를 최우선으로 합니다. 예시와 확정 규칙을 혼동하지 않습니다.
2. 한국어 **존댓말**로 간결하게 소통합니다.
3. 현재 v0.4 실행 상태와 향후 추가할 에셋을 구분합니다.
4. 사용자 원본 24장·수정 아이콘 2장과 기존 게임 버전을 덮어쓰지 않습니다.
5. 수정 전후 `docs/HANDOFF.md`의 작업·테스트·다음 할 일을 갱신합니다.

세계관의 기본은 자발적인 관계, 완전한 시민권, ‘하드한 상황과 명랑한 일상’의 공존입니다. 이 게임의 디자인은 사용자가 확정한 **럭셔리 블랙·골드**를 따릅니다.
